## Défaut de CI frontend à corriger

Le fichier `.github/workflows/monty-ci.yml` exécute actuellement :

```bash
npm run lint || true
```

Le script `lint` du frontend exécute `next lint`. Les logs du job `140643068476` montrent que Next.js 15.5.29 affiche une dépréciation, puis ouvre un assistant interactif de configuration ESLint. La commande ne réalise donc pas une vérification ESLint non interactive et son échec est neutralisé par `|| true`.

Le job est vert mais le lint n'est pas validé. Il faut migrer vers ESLint CLI, ajouter une configuration non interactive et des dépendances explicitement verrouillées dans le lockfile, puis retirer le contournement. Ne pas déclarer ce contrôle vert avant cette correction.

Le même log npm signale deux vulnérabilités dans l'arbre de dépendances (une modérée et une élevée). Les paquets concernés restent à identifier avec un audit npm complet avant toute mise à jour.
